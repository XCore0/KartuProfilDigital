# Kartu Profil Digital

Aplikasi Flutter sederhana yang menampilkan kartu profil digital Ihsan Hadi
Nugroho. Kartu berisi nama, profesi, dan deskripsi singkat.

## Menjalankan aplikasi

Pastikan Flutter sudah terpasang, lalu jalankan perintah berikut dari folder
proyek:

```sh
flutter pub get
flutter run
```

## Pengujian

Jalankan pengujian widget dengan:

```sh
flutter test
```
